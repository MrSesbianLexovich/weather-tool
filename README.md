# weather-tool
Консольная утилита на Node.js для получения прогноза погоды через открытый REST API Open-Meteo. Утилита принимает название города (или список городов), получает прогноз на несколько дней вперёд, выводит читаемую таблицу в терминал и сохраняет отчёт в JSON-файлах.

## Требования к окружению

- **Node.js 20+**
- **npm 10+**
- Доступ в интернет к `geocoding-api.open-meteo.com` и `api.open-meteo.com`
- API-ключ **не требуется**

## Установка:
```bash
git clone https://github.com/MrSesbianLexovich/weather-tool.git
cd weather-tool
npm install
```
## Переменные окружения:
Необходимо создать .env в корне проекта, пример задаваемых параметров ниже

.env.example:
```
TIMEOUT = 5000
BASE_URL_GEOCODING = https://geocoding-api.open-meteo.com/v1
BASE_URL_FORECAST = https://api.open-meteo.com/v1/forecast
REPORTS_DIR=reports
```
## Команды запуска:
```bash
# Один город, прогноз на 3 дня (по умолчанию)
node ./src/index.js --city "Москва"

# Несколько городов, прогноз на 5 дней
node ./src/index.js --city "Москва,Санкт-Петербург,Казань" --days 5

# Игнорировать кэш и выполнить запрос заново
node ./src/index.js --city "Москва" --no-cache
```
